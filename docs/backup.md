# 备份与恢复

设置 → 备份与恢复。备份书架数据库（含进度、书签）、设置、书源、封面及 WebDAV 服务器配置。不包含音频文件、下载缓存和日志。

本地备份通过系统文件选择器保存或打开 `.tbk`；WebDAV 复用已有服务器配置，默认目录 `Timbre/backup`，保留带时间戳的多个备份。

备份采用 PBKDF2-HMAC-SHA256 和 AES-256-GCM 加密，密码至少 8 位。服务器凭据包含在加密文件内，密码遗忘无法恢复。恢复支持本分支相同数据库版本的备份，不兼容其他阅读应用的备份格式。

恢复前校验密码、完整性、文件路径和数据库版本；确认后准备恢复，重启时替换数据。替换保留回滚日志，启动中断时下次启动回滚。换设备后，本地音频需要重新授权文件目录，服务器凭据会重新加密到新设备密钥库。
